# Rajat Kumar Rout — Portfolio

Personal portfolio website built with Next.js 14, Tailwind CSS, and Framer Motion.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

Zero-config deploy:

```bash
npx vercel
```

Or connect the GitHub repo to [vercel.com](https://vercel.com) for automatic deploys.

## Resume

Drop your actual `resume.pdf` into `/public/resume.pdf` to enable the download button.

## Easter Egg

Press `` ` `` (backtick) or `Ctrl+K` anywhere on the page to open the hidden terminal.

Commands: `help`, `whoami`, `skills`, `experience`, `contact`, `clear`, `exit`

## Tech Stack

- **Next.js 14** (App Router)
- **Tailwind CSS**
- **Framer Motion**
- **JetBrains Mono** + **Syne** (Google Fonts)
